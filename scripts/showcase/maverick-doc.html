Maverick

Scrolling X11 window manager. Columns, horizontal scrolling, floating windows, optional compositor. X11, Rust.

Columns

New tiled windows normally enter new columns. Each column has a width relative to the monitor workarea and can hold a vertical stack. Adding columns extends the ribbon instead of shrinking its neighbours.

Scrolling

Navigation moves the viewport through the ribbon and keeps the focused column in view:

Super+H / Super+L   focus left / right (scrolls)
Super+[/]           page-snap left / right

Floating windows

Floats belong to a monitor and workspace but not to the ribbon. They keep screen-space geometry while the tiles scroll underneath:

Super+Shift+Space   toggle floating
Super+Left-drag     move floating window

Fullscreen

Fullscreen is a presentation policy over the logical placement. Leaving it to another column keeps the flag and restore geometry.

Compositor

Plain X11 operation is the default. The optional OpenGL/GLX compositor adds opacity, rounded corners, and wallpaper without owning window state. Window management works the same with it on or off.
