Maverick / X11 window manager

A workspace with a point of view.

Maverick keeps a deliberate column ribbon in screen space. New tiled windows extend the ribbon; navigation moves the camera to the focused column; floating clients remain in the viewport.

The important detail is not the number of windows. It is that the workspace has a stable geometry and a camera.

Navigation is movement

Directional focus keeps the active column visible without shrinking its neighbours. The showcase uses this action vocabulary against the live WM, not a screenshot mock-up.

focus:left   focus:right   focus:left   focus:right

Floating is a separate coordinate space

A float can sit above the mosaic while the tiled ribbon moves beneath it. Its geometry is observed through maverickctl query tree; the showcase does not draw a fake overlay.

toggle_float → observe float → focus:right × 2 → observe again
